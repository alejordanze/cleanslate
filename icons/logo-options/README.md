# CleanSlate logo concepts

The selected Clear Folder logo is available as a [review PNG](clear-folder-preview.png) and an [editable SVG](clear-folder-logo.svg). Its wordmark sits closer to the folder than in the initial concept.

The icon-only [Clear Folder mark](clear-folder.svg) is used in the app header. The [macOS icon](../cleanslate.icns) and [transparent PNG](../cleanslate.png) use the same mark for the app and DMG volume. The logo with the wordmark remains available for larger brand placements.

Open [comparison.png](comparison.png) for a quick review or [comparison.svg](comparison.svg) for a scalable version.

| Concept | Mark | Logo with wordmark | Idea |
| --- | --- | --- | --- |
| Clear Folder | [SVG](clear-folder.svg) | [SVG](clear-folder-logo.svg) | A photo in a clean folder with a sparkle |
| Remove Layer | [SVG](remove-layer.svg) | [SVG](remove-layer-logo.svg) | A photo plus a separate metadata layer marked for removal |
| Folder Bin | [SVG](folder-bin.svg) | [SVG](folder-bin-logo.svg) | A folder with a small bin for discarded metadata |

The marks have transparent backgrounds and use the app palette: navy `#18233c`, blue `#0866ed`, and pale blue `#eaf2ff`. The wordmarks use the app's existing font stack and remain editable text in the SVGs.

Run `node icons/logo-options/build-lockups.mjs` after editing a mark to regenerate the logo SVGs and comparison SVG. The PNG is a review image captured from that comparison SVG.
