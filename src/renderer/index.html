Electron TypeScript FFmpeg bundle

Bundled media tooling, ready for desktop.

This starter resolves a static FFmpeg binary from the Electron main process, exposes it through a preload bridge, and lets you verify the runtime from the renderer.

Architecture Main + preload + renderer All written in TypeScript and built with electron-vite.
Binary ffmpeg-static Downloaded per platform and unpacked for packaging.
